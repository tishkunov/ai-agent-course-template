# M2.11 — Указатель: батчевый контракт вместо SSE

Отдельный SSE-эндпоинт снят из обязательного маршрута. Самостоятельного задания, кода и сдачи по M2.11 нет; номер сохранён для старых ссылок.

Используй [M2.1](M2.1-llm-client.md), [M2.5](M2.5-structured-output.md) и [M2.7](M2.7-extract-endpoint.md): клиент возвращает цельный `LLMResult`, схема проверяется до сохранения полей. `stream` остаётся зарезервированным параметром; `stream=True` в M2 даёт явный `LLMError(unsupported)` до сетевого вызова.
