# M2 — LLM-основы

Сохранённое обращение (`raw_text` из M1) → вызов одной выбранной модели → проверенные схемой поля и
список недостающих обязательных → запись результата в обращение и расходов в журнал вызовов. Плюс
единый клиент, через который идут все вызовы модели в следующих модулях.

Стоит на: M1 (скелет сервиса, БД, миграции, приём и аутентификация). Клиент из этого модуля
используют M3, M4, M5, M6, M7, M8.

Сквозные правила (словарь полей, достаточность, идентификаторы, порядок изменения схем) —
`../contracts.md`; при расхождении верен он.

## Как проходить пункт

Цикл M0.2: прочитать `zadanie.md` + `details/` → промпт-контракт → код от ИИ → **отдельным вызовом**
ревью по `detalnoe-review.md` → сценарии из `kriterii-priyomki.md` → запись своими словами в
`docs/decisions.md` → закрыть пункт.
