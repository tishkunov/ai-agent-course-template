# M5.5 — Поиск доступных доказательств

Требование и интерфейс — [задание](../zadanie.md), пункт M5.5; проверка — [приёмка](../kriterii-priyomki.md).

## Объяснение

Retrieval возвращает кандидатов. Это отдельный измеряемый этап: можно найти документ и исказить его в ответе, а можно не найти его вовсе. Исправления у этих ошибок разные.

## Разобранный пример

На «Работаете ли вы в выходные?» ожидается `kb/faq-1.md` с часами приёма. На вопрос о чужом договоре `kb/contract-7-1.md` не появляется среди кандидатов для доверенного клиента 9.

Сначала сохраните доступный вход и происхождение значений, затем промежуточный результат, затем итог. Почему корректный ответ не доказывает корректный фильтр retrieval?

## Частые ошибки

Кандидат с высоким score не гарантирует релевантность. Для вопроса без ответа retrieval может вернуть нерелевантные чанки — M5.8 всё равно обязан отказаться от неподтверждённого ответа.

## Промпт-контракт к ИИ

Приложите соответствующий пункт задания и сценарий приёмки; попросите реализовать его без расширения стека и скрытой подмены данных. Проведите отдельный ревью-вызов по [рискам](../detalnoe-review.md), затем проверку и запись понимания.
