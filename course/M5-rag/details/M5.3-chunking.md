# M5.3 — Нарезка с сохранением условий

Требование и интерфейс — [задание](../zadanie.md), пункт M5.3; проверка — [приёмка](../kriterii-priyomki.md).

## Объяснение

Чанк — фрагмент для поиска. Перекрытие помогает сохранить факт на границе, но не гарантирует сохранение исключения. Проверять нужно содержимое фрагментов, а не только их размеры.

## Разобранный пример

В `garantia_usloviya.pdf` срок 12 месяцев с даты акта соседствует с исключением для повреждений по вине клиента. Учебная строка прайса «Мытьё — 500 ₽/м², минимум 2 м²» должна сохранить единицу и минимум; это явно заданный пример, не строка существующего прайса.

Сначала сохраните доступный вход и происхождение значений, затем промежуточный результат, затем итог. Как тест поймает потерю исключения при границе чанка?

## Частые ошибки

Короткий документ может быть одним чанком. Огромная строка не должна молча обрезаться токенайзером; зафиксируйте контролируемую ошибку или разделение с повтором заголовка.

## Промпт-контракт к ИИ

По циклу M0 укажите scope только M5.3, текущие интерфейсы и миграции. Приложите соответствующий пункт задания и сценарий приёмки; попросите реализовать его без расширения стека и скрытой подмены данных. Проведите отдельный ревью-вызов по [рискам](../detalnoe-review.md), затем проверку и запись понимания.

## Что именно сравнить при нарезке

Учебный текст: «Гарантия — 12 месяцев с даты акта. Повреждения по вине клиента исключены».
Плохой результат: чанк A содержит только срок; чанк B — исключение без указания, к чему оно относится.
Хороший для этого короткого текста результат: оба предложения в одном чанке. Для длинного раздела
покажите фактическую границу выбранного размера и второго размера: есть ли хотя бы один чанк,
в котором условие и исключение читаются вместе. Большее перекрытие само по себе это не доказывает.

Для строки «Мытьё — 500 ₽/м², минимум 2 м²» разделение после «500 ₽» скрывает единицу и минимум.
Сохранение строки вместе с заголовками даёт проверяющему все условия расчёта. Сумма по такой строке
остаётся неизвестной, пока клиент не сообщил площадь; пример не подменяет SQL-прайс приложения.
