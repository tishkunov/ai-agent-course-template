# M8 — Детальное ревью

Требования — в задании, воспроизводимые сценарии — в приёмке. Этот документ ищет риски
реализации и не вводит новых задач. Прогоняй отдельным вызовом критика по M0.

## M8.1 — Приём и публикация

Проверь окно между commit PostgreSQL и XADD: 503 должен сохранять доступную клиенту идентичность, а повтор входа допубликовывать прежний event. Ошибка «вход уже есть, значит больше ничего не надо» оставляет обращение без обработки. Лимит очереди не должен удалять pending. Нового outbox или второго брокера нет.

## M8.2 — Завершение события

Смотри порядок checkpoint/result → processed → ack. Проверка наличия маркера не заменяет идемпотентность эффекта M6. Убедись, что recovery сохраняет run/action IDs, новая реплика меняет event/run IDs и что worker реально забирает pending после падения. XACK не означает удаление stream-entry. Сохранённая пауза уже обработана. Ошибка marker/ack не переписывает сохранённый результат на failed.

## M8.3 — Политика повторов

Перемноженные retry-циклы SDK, wrapper и fallback могут пройти одиночный тест и разогнать расходы. Breaker основной модели не должен открывать breaker запасной. Таймаут после эффекта не разрешает повторить бизнес-функцию вне журнала M6. Сумма вызовов должна включать ошибки. Все adapter attempts делят общий лимит tool-loop M6 максимум 5, включая retry/fallback.

## M8.4 — Деградация

Проверь, что unknown-условие не превращено в ok под видом частичного результата. Прайс/зона/доступ не заменяются догадкой модели или кешем другого scope. Если БД не сохранила эскалацию, событие нельзя назвать завершённым.

## M8.5 — Запасная модель

Журнал должен стоять у каждой фактической попытки, а не только у окончательного LLMResult. Внешняя обёртка не должна ещё раз записывать успех с новым ID. Сигнатура клиента прежняя; переключение не снимает schema/tools/access/budget ограничения.

## M8.6 — Кеш

Права и версии проверяются до семантического поиска и возврата ответа. Источники и scope сохраняются вместе с ответом. Порог не подбирается только на положительных перефразировках. Обёртка кеша не применяется ко всему графу или extracted_fields.

## M8.7 — Бюджет

Агрегат восстанавливается из журнала без повторного A; null не становится нулём. Scope не строится из телефона. Проверка действует перед каждой попыткой, включая fallback. У одного worker ограничение объяснимо; строгую гарантию для конкурентных процессов не заявлять.

## M8.8 — Нагрузка

Проверь преобразование bulk во вход API и отсутствие live-моделей в основном прогоне. Счётчики различают unique event и HTTP/stream попытки, ack паузы и done обращения. Медленная БД не доказывает блокировку event loop; предел ожидания и остаток backlog должны быть видны.
