# M6 — Агент и оркестрация

Один граф LangGraph соединяет M2–M5: сначала тип обращения, затем подходящая ветка проверки, уточнения, ответа или оператора. Внутри узла модель выбирает инструменты чтения в ограниченном цикле. Код проверяет права и разрешает действия; журнал и checkpoint позволяют продолжить после сбоя.
