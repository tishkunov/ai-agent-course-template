# M7 — Оценка качества и безопасности

Модуль объединяет малые проверки M2–M6 и добавляет регрессии, атаки и контроль ложных отказов. Результат — воспроизводимый локальный gate с раздельными оценками качества, эффектов и доступа. Моки проверяют механизм; live-прогон — реальные предсказания. M9 для сдачи не нужен.
