# M7 — Риски для отдельного ревью

Отдельный вызов по M0 рассматривает реализацию против [задания](zadanie.md); конкретные наблюдения — в [приёмке](kriterii-priyomki.md). Не вводить новых требований только в ревью.

| Пункт | Риск и место проверки |
|---|---|
| M7.1 | Результат моков, качество модели и эффект смешаны одним score. Проследить mode от входа кейса до отчёта; действие проверяется БД, не судьёй |
| M7.2 | Gold незаметно попал в runtime-input; ID join подтянул скрытую сумму/услугу. Проверить adapter inputs, split и review-manifest; disputed/not_run не исчезли из coverage. Операторское решение и валидный JSON не делают эталон истинным |
| M7.3 | Нормализация стёрла значимое число/отрицание; null назван успехом для любого пустого предсказания. Проверить знаменатели, support=0, несколько эффектов при одном ожидаемом, полную причину validation и неполную RAG-разметку |
| M7.4 | Судья не получил вопрос/источники либо получил запрещённые; ответ сам приказал себе оценку. Проверить роли и схему, ручную калибровку до использования, false pass отдельно от общего согласия и учёт вызовов |
| M7.5 | Baseline сдвигается автоматически; набор/модель/KB изменены незаметно; исключение превращается в пустой успешный результат. Проверить manifest equality, run_status и policy до выбора кандидата |
| M7.6 | Мок всегда безопасен и ничего не проверяет; фраза отказа скрывает уже выполненный вызов. Найти malicious proposal, spy перед исполнением, проверку БД, полезный похожий запрос, фактическую загрузку вложения |
| M7.7 | Отрицательный ACL-тест проходит потому, что документа нет вообще. Найти положительный запрос client7; проверить scope на каждом ходе и отсутствие сырого чужого текста до модели. Маскирование логов не должно портить разрешённое рабочее состояние/собственное подтверждение |
| M7.8 | Security растворился в среднем качестве, not_run скрыт, CLI вернул 0 при fail. Проследить error propagation, persisted report и exit status; отчёт не содержит сырой PII под видом evidence |

Заключение содержит риски, места в реализации, сценарий воспроизведения и ограничения проверки. Не утверждать «безопасность доказана» по конечному набору; не считать отсутствие M9 поводом пропустить уже наблюдаемые эффекты M6.
