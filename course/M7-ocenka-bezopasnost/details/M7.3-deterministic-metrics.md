# M7.3 — Число и его знаменатель

Детерминированная метрика означает повторяемую арифметику на фиксированных предсказаниях, а не детерминированную модель. Предсказания сохраняются с версиями; формулы применяются после этого.

Для адресов [Абая 10, null, Мойка 12, null] модель вернула [Абая 10, Выдуманный 5, Мойка 12, null]. Exact match — 3/4. Но среди двух случаев отсутствия адреса есть одна выдумка, значит false filling — 1/2. Одна общая accuracy прячет важный вид ошибки.

Type и priority — две задачи. Для каждого класса выводите TP/FP/FN/support и F1; пустой класс не получает 100%. Validation с одинаковой базой «данных_нет» может иметь разные причины: полная строка/причина проверяется отдельно. Route-unit с явным состоянием нельзя складывать в одну accuracy с end-to-end, где ошибки могли начаться в извлечении.

В RAG gold часто перечисляет только файл. По нему считают попадание документа, а не точность каждого чанка. Например гарантия есть в FAQ и PDF, но исходный gold перечисляет PDF; ответ по FAQ нужно проверить по содержимому, а не автоматически назвать галлюцинацией. На вопросе без источника recall не определён — есть отдельный тест отказа.

Пустой обязательный набор и обрыв на середине — неполная оценка. Проверка N=0 обязана проверить не только отсутствие ZeroDivisionError, но и блокировку ложного pass. Для эффектов считать ticket/исходящие по стабильным ключам M6 и проверять параметры, а не фразу модели.
