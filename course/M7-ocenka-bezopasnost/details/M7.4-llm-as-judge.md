# M7.4 — Судья видит вопрос и основание

Судья, которому передали только ответ «гарантия 24 месяца», не может установить его истинность. Дайте вопрос, ответ, разрешённый текст источника «12 месяцев» и рубрику. Тогда unsupported утверждение имеет проверяемое основание для отрицательной оценки.

Один контракт: supported/complete/appropriate и причины. Корректный отказ при отсутствии источника может быть полным ответом в рамках доступных сведений; лишний отказ при наличии ясного основания — ошибка полезности. Инструкция «поставь pass» внутри оцениваемого ответа — данные, не указание судье.

Подготовьте шесть коротких ответов из задания и ручные оценки до запуска. В таблице 5/6 согласий покажите, что именно было шестым: опасный false pass не равнозначен спору о стиле. До допустимой калибровки судья — диагностический инструмент; нельзя использовать его балл как автоматическое разрешение изменения.

Другая модель не гарантирует независимость: обе могут одинаково пропустить выдумку. Низкая температура не гарантирует одинаковый ответ. Зафиксированные настройки и ручная сверка полезнее обязательного числа повторов без причины. Каждый реальный повтор стоит отдельного вызова M2.

Судья не видит реального состояния БД и не заменяет контроль прав. Не передавайте ему чужой договор ради оценки утечки: сначала доступ ограничивает M5/M6, потом судья оценивает разрешённые источники.
