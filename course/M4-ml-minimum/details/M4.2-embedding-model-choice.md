# M4.2 — Одна фиксированная модель

Прежнее сравнение кандидатов снято. Эта справка используется внутри [M4.1](../zadanie.md#m41--векторы-и-ближайшие-примеры), отдельной сдачи нет.

Учебная конфигурация:

```text
model = sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
revision = e8f8c211226b894fcb81acc59f3b34ba3efd5f42
device = cpu
dimension = 384
max_seq_length = 128
normalize_embeddings = true
k = 3
```

Выбрана одна многоязычная модель с поддержкой русского, доступная через Sentence Transformers. Размерность и лимит подтверждены [карточкой автора](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2); точная revision — [метаданными репозитория модели](https://huggingface.co/api/models/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2). Проверено при редактуре 2026-09-19. Передавать revision явно, не использовать плавающий `main`.

В проекте Python 3.12; рекомендации [официальной установки Sentence Transformers](https://www.sbert.net/docs/installation.html) допускают эту версию Python. Библиотеки embedding пока не входят в каркас M1: при реализации студент добавляет обычную inference-зависимость, фиксирует разрешённые версии в lock-файле и проверяет загрузку/один batch на CPU в своей среде. Проверка документации не означает, что runtime модели уже установлен или испытан в этом репозитории. Обучающие дополнения и GPU не требуются.

128 — токены токенизатора модели, не символы и не токены LLM M2. Размерность 384 определяет форму индекса M5. Русский в поддерживаемых языках не гарантирует качество на обращениях проекта: ограничение проверяется реальным сравнением M4.3. k=3 ограничивает голосование тремя примерами, а не выбирает три типа.

Manifest связывает модель, revision, версии библиотек, нормализацию и хеш данных. Смена любой составляющей требует проверки совместимости базы. Запись решения по M0 объясняет эти параметры и наблюдаемые ограничения, без исследования рынка моделей.
