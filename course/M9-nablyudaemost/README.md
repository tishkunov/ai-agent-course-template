# M9 — Наблюдаемость

Видимость системы: сквозной трейс каждого прогона агента (Langfuse), структурные связанные логи, технические метрики (latency, ошибки, очередь, кеш) и бизнес-метрики (авто/эскалации, стоимость на обращение, объём), дашборд и пороговые алерты.

Стоит на: M1–M8. Сквозной механизм поверх пайплайна S1–S10 (см. `course/README.md` → «Сквозные механизмы»): наблюдаемость. Деплой/CI/CD в модуле нет.

## Порядок работы

M9.1 один run в Langfuse → M9.2 JSON-логи → M9.3 технические агрегаты и M9.4 бизнес-формулы →
M9.5 Grafana на полученных данных → M9.6 локальный firing/resolved alert. Через все пункты
проходят два запуска одного сценария: штатный A и новое обращение B с таймаутом модели.

Один request может иметь несколько run/trace. Период, когорта и знаменатели подписываются;
источник расходов — журнал M2/M8. Сбой экспорта не останавливает обработку, но часть телеметрии
может потеряться. Стек не расширяется. Сквозные правила — [contracts.md](../contracts.md).
