# M9.4 — Формулы с явным периодом

## Что это и зачем

Доля без знаменателя неоднозначна. Когорта — обращения, созданные в [T0,T1); снимок S
фиксирует их состояние. Молодая когорта включает ожидающих. История escalations нужна даже
для текущего done: помощь оператора не исчезает после успешного действия.

Полные формулы находятся в M9.4 задания; здесь не вводится альтернативное определение.

## Разобранный пример

Четыре обращения: done авто, escalated, done после оператора, need_info.
Авто = 1/4, с эскалацией = 2/4. Стоимости двух вызовов первого 0,01+0,02 и третьего 0,04
дают известные 0,07; неизвестный расход второго остаётся отдельной строкой. Средняя известная
часть 0,0175 не является полной средней стоимостью.

## Что сделать по шагам

1. Зафиксируй [T0,T1), S и когорту; выбери запросы к существующим таблицам.
2. Агрегируй llm_calls по уникальному call_id через request_id без умножающего JOIN с actions.
3. Отдельно считай календарные расходы периода; не дели их на объём чужой когорты.
4. Обработай пустую когорту как n/a, текущий интервал как неполный; проверь ручную фикстуру.

## Промпт-контракт к ИИ

Передай таблицу формул из задания и фикстуру четырёх обращений. Попроси SQL/функции на существующих таблицах, не новые независимые бизнес-счётчики.

## Риски и проверка

Последний route заменил историю участия оператора; JOIN размножил cost по числу actions; null стал нулём; известная часть названа полным счётом; разные периоды смешаны.

Поведение задаётся в [задании](../zadanie.md), точная проверка — в соответствующем пункте
[приёмки](../kriterii-priyomki.md). После кода нужен отдельный вызов ревью по M0.
