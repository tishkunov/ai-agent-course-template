# M0.4 — Промпт-контракты и методика порогов

## Зачем это

«Сделай мне модуль извлечения полей» даёт непредсказуемый результат: ИИ додумывает требования, реализует заодно кусок следующего модуля, меняет уже согласованную сигнатуру. Промпт-контракт — это узкий, дословный ввод: ровно текущий пункт плюс то, что нельзя трогать. Чем точнее вход, тем управляемее выход.

Отдельная тема — числа. Пороги (`confidence`, `MAX_CLARIFY_ROUNDS`, TTL кеша, recall@k) нельзя брать «на глаз» или из статьи. У выбора должна быть явная альтернатива и причина, почему выбрано это значение, — иначе в проекте окажется число, которое никто не может объяснить.

## Как на практике

**Шаблон промпт-контракта на реализацию** (`docs/prompt_templates.md`):

```
Реализуй ТОЛЬКО пункт M{n}.{x}.

Цель: <дословно из zadanie.md>
Что сделать: <дословно>
Контракты: <дословно>
Краевые случаи: <дословно>

Неизменяемые ограничения (не переписывать):
<сигнатуры/схемы из уже закрытых пунктов>

Запреты:
- не реализуй ничего за пределами M{n}.{x};
- не меняй перечисленные контракты — если считаешь, что надо, скажи отдельно, я оформлю решением.
```

**Шаблон промпта на выбор порога:**

```
Нужно выбрать значение <параметр> для <контекст>.
Дай 2–3 варианта. Для каждого: значение, что улучшает, что ухудшает (trade-off),
при каких данных подходит. Не давай одно «правильное» число.
```

Пример trade-off для `MAX_CLARIFY_ROUNDS`: меньше кругов → быстрее эскалация, но больше ложных эскалаций; больше кругов → лучше UX, но дольше цикл и дороже. Прогоняешь на своих синтетических данных где можно, выбираешь, пишешь в `decisions.md`: значение + альтернативы + причина.

Оба шаблона примени хотя бы раз до конца M0: реализацию — на `/ping` в M0.5, порог — на любом тренировочном примере (например гипотетический таймаут вызова).

## Частые ошибки

- В промпт-контракт не вложены неизменяемые контракты — ИИ переписывает сигнатуру.
- ИИ предложил «заодно» сделать следующий пункт, и это приняли «бонусом» вместо отдельного решения.
- Порог получен одним числом с уверенным тоном, без альтернатив.

## Готово, когда

Оба шаблона написаны и хотя бы раз применены; промпт-контракт из M0.5 можно предъявить текстом. См. `kriterii-priyomki.md` § M0.4.
