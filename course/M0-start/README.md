# M0 — Старт

Не код, а процесс: рабочий цикл, по которому весь курс собирается с ИИ, и три артефакта на весь курс — `docs/working_agreement.md`, `docs/decisions.md`, `prompts/`. Проходится до M1, пока нет реальной технической сложности.

Стоит на: ничём. Всё остальное (M1–M9) опирается на процесс, заведённый здесь.

## Файлы модуля

| Файл | Назначение |
|---|---|
| `zadanie.md` | что сделать: Цель · Что сделать (+ где нужно — Контракт / Краевые случаи / Результат), по пунктам M0.1–M0.8; плюс раздел «Общие правила курса» |
| `details/M0.x-*.md` | по одному файлу на пункт: зачем он нужен + как пройти на практике + частые ошибки |
| `kriterii-priyomki.md` | чем принимать пункт и модуль |
| `detalnoe-review.md` | на что смотреть отдельным ревью-вызовом |

## Итог модуля

`docs/working_agreement.md` (роли + границы доверия + политика расхождения/затыка), заведённые `docs/decisions.md` и `prompts/`, и один полный прогон цикла из 7 шагов на игрушечной задаче `GET /ping` (M0.5). Дальше этот цикл применяется к каждому пункту M1–M9 без изменений.
