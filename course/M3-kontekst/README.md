# M3 — Контекст

Результат: неполная заявка → конкретный вопрос → сохранённая пауза → ответ в том же обращении после перезапуска. Далее — ограничение контекста и summary без потери исправлений. До M4 используются заранее известные заявки; граф M6 и внешние мессенджеры не нужны.
