# Практический курс: AI-агент обработки входящих заявок

Сквозной проект — сервис, который принимает обращения (почта / форма / мессенджер) и сам доводит их до результата: классифицирует → извлекает поля → валидирует по базе → выбирает маршрут (авто / уточнение / эскалация оператору) → выполняет действие. Спорное уходит человеку (HITL). Растёт по модулям M0–M9, каждый добавляет один слой.

Стек: Python 3.12 / FastAPI / SQLAlchemy 2.0 async + Alembic / PostgreSQL + pgvector / Redis / LangGraph / MCP / sentence-transformers / Langfuse.

## Что где лежит

| Путь | Что это |
|---|---|
| `ai_context/` | Мастер-контекст курса мелкими файлами: `00–14` — роль ассистента, полный контекст проекта, стек и данные по модулям, контракты, процесс; `15–22` — гейты, выбор модели, роли сабагентов, плейбуки, детальный чек-лист ревью. Индекс — `ai_context/README.md`. Держать открытым при работе. |
| `course/` | Разбор ТЗ по модулям. В каждой `M{n}-*/`: `README.md` (маршрут) + `zadanie.md` (что делать по пунктам) + `details/` (объяснения) + `kriterii-priyomki.md` (чем принимать) + `detalnoe-review.md` (что ревьюить). |
| `data/` | Синтетические данные для разработки и проверки (пакет `course-pack-1`): справочники, обращения, диалоги, eval-эталоны, база знаний, security-кейсы, нагрузочные потоки. Описание — `data/README.md`. |
| `.claude/agents/` | Проектные сабагенты Claude Code без встроенного эквивалента: `analyst`, `plan-reviewer`, `tester`, `final-reviewer`, `debugger`. |

## Как работать

Цикл на один пункт `M.x` (подробно — `ai_context/4-process/12-process-raboty.md`, `course/M0-start/zadanie.md`):

1. Открыть `course/M{n}-*/zadanie.md`, найти пункт.
2. Собрать промпт-контракт: Цель + Требования + Контракты + Краевые случаи + неизменяемые контракты (`ai_context/3-priyomka/11-stabilnye-kontrakty.md`).
3. Получить код — `implement` / сабагент `implementer`.
4. **Отдельным вызовом** — ревью по `course/M{n}-*/detalnoe-review.md` + чек-лист `ai_context/3-priyomka/22-review-detalno.md`.
5. Тесты + «Готово, когда» из `course/M{n}-*/kriterii-priyomki.md`.
6. Пересказать «Понять» своими словами в `docs/decisions.md`.
7. Отметить в `docs/progress.md`.

Модель для работы (сессия, сабагенты, «оркестратор») — любая удобная; `ai_context/5-instrumenty/16-model-tiering.md` даёт только ориентир по нагрузке.

Перед началом скопируйте `working_agreement.md`, `decisions.md`, `progress.md` и `prompt_templates.md` из `docs/_templates/` в `docs/`. Рабочие записи и локальные настройки исключены из Git; шаблоны остаются частью курса. Промпты проекта ведутся в `prompts/`. Наличие файла не означает завершённую приёмку. Техническая навигация — [course/README.md](course/README.md), общие правила — [course/contracts.md](course/contracts.md).
