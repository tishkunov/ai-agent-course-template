# .claude/hooks/ — хуки рабочего цикла

Хуки — механизм Claude Code «сделать X автоматически при событии Y». `ai_context/5-instrumenty/14-skilly-i-agenty-detalno.md` §11.4 прямо говорит: автоповедение «каждый раз когда…» реализуется хуком в `settings.json`, а не памятью/договорённостью. Здесь — два хука цикла M0.2.

Образец конфигурации — `.claude/settings.example.json` → `hooks`. Если нужны эти хуки, скопируйте образец в локальный `.claude/settings.json`; разрешения инструментам настройте самостоятельно. Посмотреть/выключить их в рантайме: команда `/hooks`.

## `ruff-on-write.sh` — авто-lint/format Python

- **Событие:** `PostToolUse`, matcher `Write|Edit`.
- **Что делает:** после каждого редактирования `.py`-файла под `app/` прогоняет `ruff check --fix` + `ruff format` по этому файлу.
- **Файлы вне `app/**/*.py`** — молча пропускаются.
- **`ruff` не установлен** (до M1) — хук печатает `systemMessage` и выходит с кодом 0, ничего не ломая.
- Парсит stdin через `python3` (не `jq`), т.к. `jq` в системе может не быть.

## `pytest-before-commit.sh` — тесты как гейт коммита

- **Событие:** `PreToolUse`, matcher `Bash`, фильтр `"if": "Bash(git commit:*)"`.
- **Что делает:** перед `git commit` прогоняет `pytest -q`. Красные тесты → `exit 2` → коммит блокируется. Это принцип №6 из `ai_context/4-process/21-core-principles.md`.
- **`pytest` не установлен / тестов ещё нет** (`rc=5` «не собрано ни одного теста») — не блокирует.

### Компромисс по фильтру `git commit`

Поле `"if": "Bash(git commit:*)"` матчит команду по префиксу. Оно **не** поймает `git commit`, спрятанный в составной команде (`cd sub && git commit …`, `x && git commit`). Это осознанное упрощение: сам скрипт всё равно прогоняет тесты, а не полагается только на фильтр; для 99% случаев (`git commit -m "…"` первой командой) фильтр отсекает лишние запуски pytest на любом другом Bash-вызове. Если понадобится жёстче — убрать `if` и добавить в начало скрипта проверку `grep -q 'git commit'` по `tool_input.command` из stdin.

## Проверка, что хуки подхватились

Claude Code следит за `.claude/` только если файл настроек существовал на старте сессии. Если хуки не срабатывают после первого создания `settings.json` — открыть `/hooks` один раз (перечитает конфиг) или перезапустить сессию.
