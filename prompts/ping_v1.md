# Задача: реализовать пункт M0.5 — пробный прогон цикла (`GET /ping`)

## Цель
Пройти весь цикл M0.2 от начала до конца на маленькой задаче вне пайплайна проекта — до того, как в M1 появится реальная сложность. Здесь важен прогон процесса (промпт-контракт → код → **отдельное** ревью → тест → «Понять» → запись в `decisions.md`), а не стек.

## Требования
1. Игрушечная задача вне пайплайна проекта: `GET /ping` → JSON `{status: "ok", version: str, ts: datetime}`.
2. Один тест: на HTTP 200 и на форму ответа (три поля, `status == "ok"`, `version` — непустая строка, `ts` — валидный ISO-8601 datetime).
3. Стек — любой минимальный. Допустимо голое FastAPI + Uvicorn, без Docker и без БД (см. `docs/decisions.md` ADR-0001). Цель пункта — процесс, не инфраструктура.
4. `version` берётся из одного места (константа модуля или переменная окружения с дефолтом), не хардкодится в хендлере по месту.
5. `ts` — timezone-aware UTC (`datetime.now(UTC)`), не наивный.

## Контракты / интерфейсы
- Эндпоинт: `GET /ping` → `200` с телом `{status, version, ts}`; иных кодов у пункта нет.
- Ответ типизирован pydantic-схемой (`response_model`), не собирается «руками» из `dict`.
- Итог пункта — одна запись в `docs/decisions.md` со всеми полями (пункт, промпт-контракт = этот файл, что нашло отдельное ревью, ответ на «Понять»).

## Краевые случаи
- Отдельный ревью-вызов ничего не нашёл на тривиальном примере — ожидаемо; фиксируем сам факт (и это повод перепроверить, не слишком ли мягкий был критик-промпт). Если нашёл даже мелочь — фиксируем находку.
- `version` не задан в окружении → берётся дефолт из кода, эндпоинт не падает.

## Неизменяемые ограничения (зафиксированные контракты)
На M0 их ещё нет — `ai_context/3-priyomka/11-stabilnye-kontrakty.md` пуст по сути до M2.1. Первым здесь фиксируется только конвенция `prompts/<step>_v<N>` (этот файл — её первое применение).

## Стек
Python 3.12, FastAPI, Uvicorn, pytest + `httpx.AsyncClient`. Ничего сверх этого для M0.5 не нужно.

## Запреты
- НЕ реализуй ничего из M1+ (никакого Postgres, Alembic, Docker, JWT, Redis, слоёв `services/db/models` — это M1.1, отдельный осознанный шаг, не «бонус» к M0.5).
- НЕ проводи ревью в этом же ответе — ревью будет отдельным вызовом ИИ в роли критика (шаг 4 цикла M0.2).
- Тест проверяет «что эндпоинт обязан вернуть по Требованиям/Контрактам» (код 200 + форма), не «что код делает» постфактум.

## Формат ответа
- Код: `app/main.py` (или `main.py`) + `tests/test_ping.py`. Без модулей-«свалок».
- Отдельно — список файлов и одна строка «что где».
- Команда запуска теста.
