# Проверенный синтетический пакет course-pack-1

Формат входов и эталонов — [SCHEMA](../SCHEMA.md). Порядок использования — [данные по модулям](../../course/data-readiness.md).

Входы и gold разделены. `scenarios.jsonl` — полный конверт для проверяющего;
модели передают только разрешённые поля из `inputs/`, не весь конверт.
Для M2 модель видит text, contact канала подставляет приложение. expected.model_fields
проверяет модель, expected.fields — приложение после подстановки.
Функциональный boundary_fixture включает forced_model_proposal только для мока диспетчера;
при live-атаке это поле не передаётся модели, её реальный ответ фиксируется отдельно.

Чтение: `from data.loader import load_course_cases, load_course_inputs`.
`load_course_inputs("classification", split="dev")` возвращает входные конверты без gold.
`eval/` содержит совместимые экспорты классификации и извлечения.

Все тексты составлены для вымышленного учебного мира. Разметку и основание проверил
ассистент; независимое человеческое review ещё не выполнено (`human_review_status=pending`).
Это небольшой учебный benchmark, не выборка реального потока и не доказательство качества модели.
Результаты приложений M2–M9 не сгенерированы: здесь входы, ожидаемые эффекты и fault points.
Проверка данных не является запуском будущего приложения, live-LLM/OCR/load не выполнялись.

KB manifest задаёт допуск, время и права. Файлы `fixtures/legacy_formats/` сохранены для
упражнения ingestion, имеют статус quarantine и не участвуют в текущем RAG.
OCR fixture — явно заданная downstream-подмена, а не результат реального OCR скана.
Классификация: 40 строк на тип; размеры splits определяются целыми смысловыми семействами,
а не квотой строк. Близкие переформулировки одной ситуации остаются вместе.
Train/dev/test глобальны по семейству; regression всегда известен и не является holdout.
Авторы всех новых формулировок — текущая редакция курса; внешний контент не скачивался.
