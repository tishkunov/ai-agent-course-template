# Регламент приёма заявок

1. Обязательные поля заявки: тип услуги, адрес, контактный телефон.
2. Если не хватает обязательного поля — оператор запрашивает уточнение, заявка в статусе need_info.
3. Приоритет «срочный» ставится при словах об аварии (затопило, замыкание, нет тепла зимой).
4. Спам и нерелевантные обращения отклоняются без ответа.
5. Заявки с суммой выше 15000 ₽ передаются менеджеру (эскалация).
