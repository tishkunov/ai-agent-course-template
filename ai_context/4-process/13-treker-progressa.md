# Трекер прогресса (шаблон)

## 10. Трекер прогресса (шаблон)

Завести файл `docs/progress.md`, по одной строке на пункт (пример на M1):

```
- [ ] M1.1 Структура проекта и окружение — закрыт: __ (дата), decision: __
- [ ] M1.2 Типизация и pydantic
- [ ] M1.3 Асинхронность
...
- [ ] M1 — интеграционная приёмка модуля
```

Заполняется по ходу всего курса (M0–M9), не задним числом — иначе теряется смысл «известных ограничений» из `../3-priyomka/10-kriterii-kachestva.md` §7.4.
