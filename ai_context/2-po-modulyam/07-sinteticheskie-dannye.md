# Данные по модулям

Использовать только `data/course_pack/`. Карта задач, количества и границы проверки:
[course/data-readiness.md](../../course/data-readiness.md).
Форматы и загрузка: [data/SCHEMA.md](../../data/SCHEMA.md).

Для входов — `data.loader.load_course_inputs`, для эталонов тестового адаптера —
`load_course_cases`. Разметка, идентификаторы кейсов и управляющие фикстуры не входят
в промпт. Train/dev/test поставляются готовыми и разделены по смысловым семействам.
Наличие test в учебном наборе не делает его закрытым экзаменационным набором.

Сохранять учебные дефекты: конфликтующие и исторические документы, карантин ingestion,
отрицательные сценарии доступа, security payloads, ретраи и отказы зависимостей.
Manifest и права доступа — необходимые данные задания, а не лишние метаданные.
