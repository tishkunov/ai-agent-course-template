# Режимы работы ИИ по модулям

## 5. Каталог скиллов ассистента по модулям (режимы работы ИИ)

| M | Основной режим ИИ | На что специально давить |
|---|---|---|
| M0 | Модератор процесса | не давать закрыть пункт без отдельного ревью-прохода и письменного «Понять» |
| M1 | Backend-реализатор + ревьюер слоёв | границы слоёв (api/services/db/models/schemas), отсутствие блокирующих вызовов в async, секреты не в коде |
| M2 | Prompt/LLM-инженер | структура messages по ролям, temperature=0 для извлечения, structured output вместо парсинга текста, стоимость считается с первого вызова |
| M3 | Диалоговый инженер | состояние диалога только в БД, «потерянное в середине», лимит кругов, идемпотентность исходящих |
| M4 | Наставник по прикладной классификации | одна фиксированная модель, ближайшие примеры и правило приоритета; сравнение с LLM, метрики по типам и честное указание загрязнения test |
| M5 | RAG-инженер | опора на источник («данных нет» вместо выдумки), разделение SQL (структурное) vs RAG (регламентное), различение ошибки retrieval vs генерации |
| M6 | Агентный архитектор | явное состояние графа, идемпотентность действий, guardrails как обёртка, модель предлагает инструменты, код проверяет права/лимиты, оператор подтверждает разрешённое |
| M7 | Red-team / security-ревьюер / калибровщик judge | реально пытаться сломать guardrails, а не подтверждать что «должно работать»; судья сверяется с ручной разметкой |
| M8 | SRE-ревьюер | таймаут+ретрай+breaker на каждом внешнем вызове; кеш не трогает решения по обращению, только знания |
| M9 | Observability-ревьюер | трейс покрывает все шаги, не только финал; бизнес-метрики и технические разведены; стоимость сходится с `llm_calls` |

Кросс-модульный режим «критик» (M0.2, шаг 4) активен на любом M — задача не подтвердить код, а прогнать «Ревью»-чек-лист конкретного пункта и явно назвать, что не соответствует. Построчные чек-листы разложены по модулям: `course/M{n}-*/detalnoe-review.md` (сводная навигация — `../3-priyomka/09-master-cheklist-review.md`). Соответствие «задача → скилл/агент» — в `../00-navigatsiya.md` и `../5-instrumenty/14-skilly-i-agenty-detalno.md`.
